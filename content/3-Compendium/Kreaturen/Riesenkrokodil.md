## Merkmale

***Atem anhalten:*** Das Krokodil kann eine Stunde lang den Atem anhalten.

## Aktionen

***Mehrfachangriff:*** Das Krokodil führt einen Bissangriff und einen Schwanzangriff aus.

***Biss:*** *Nahkampfangriffswurf:* +8, Reichweite 1,5 m. *Treffer:* 21 (3W10+5) Stichschaden. Wenn das Ziel eine Kreatur von höchstens großer Größe ist, wird es [[Gepackt|gepackt]] (Flucht-SG 15). Das gepackte Ziel ist außerdem [[Festgesetzt|festgesetzt]] und kann nicht zum Ziel vom Schwanzangriff des Krokodils werden.

***Schwanz:*** *Nahkampfangriffswurf:* +8, Reichweite 3 m. *Treffer:* 18 (3W8+5) Wuchtschaden. Wenn das Ziel eine Kreatur von höchstens großer Größe ist, wird es umgestoßen und hat den Zustand [[Liegend|Liegend]].
