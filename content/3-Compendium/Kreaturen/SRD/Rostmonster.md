# Rostmonster

## Talente

### Eisenwitterung:
Das Rostmonster kann eisenartiges Metall im Abstand von bis zu neun Metern von sich wittern und lokalisieren.


## Aktionen

### Mehrfachangriff:
Das Rostmonster führt einen Bissangriff aus und setzt zweimal Antennen ein.

### Biss:
*Nahkampfangriffswurf:* +3, Reichweite 1,5 m. *Treffer:* 5 (1W8+1) Stichschaden.

### Antennen:
Das Rostmonster zielt auf einen nichtmagischen metallischen Gegenstand – eine Rüstung oder eine Waffe – der von einer Kreatur im Abstand von bis zu 1,5 Metern von ihm getragen oder gehalten wird.*Geschicklichkeitsrettungswurf:* SG 11; die Kreatur mit dem Gegenstand. *Misserfolg:* Der Gegenstand erhält einen Malus von −1 auf die RK, die er bietet (Rüstung), oder auf Angriffswürfe, die mit ihm ausgeführt werden (Waffe). Eine Rüstung wird zerstört, wenn der Malus ihre RK auf 10 verringert. Eine Waffe wird zerstört, wenn der Malus −5 erreicht. Der Malus kann aufgehoben werden, indem der Zauber *[[3-Compendium/Zauber/Ausbessern|Ausbessern]]* auf die Rüstung oder die Waffe gewirkt wird.

### Metall zerstören:
Das Rostmonster berührt einen nichtmagischen metallischen Gegenstand im Abstand von bis zu 1,5 Metern von sich, der weder getragen noch gehalten wird. Die Berührung zerstört einen Würfel von 30 Zentimetern Kantenlänge des Gegenstands.
